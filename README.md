# PRANAV

### Connecting People. Supporting Care.

**PRANAV** is a patient-centric healthcare coordination platform designed to connect emergency blood requirements with potential blood resources, donor networks, and authorised healthcare facilities through a structured digital coordination journey.

---

## 🩸 From Blood Search to Blood Coordination

In an emergency, simply finding a blood resource is often not enough.

PRANAV is designed around the complete coordination journey:

**Emergency Request → Requirement Analysis → Smart Matching → Resource Discovery → Verification → Coordination → Status Tracking → Resolution**

The platform focuses on making emergency coordination more structured, accessible, and easier to understand.

---

## 🚨 Key Features

### Emergency Blood Request
Create a structured emergency blood requirement with:

- Blood group
- Blood component
- Required units
- Urgency
- City / District
- Hospital / Healthcare facility
- Required date and time
- Contact preference
- Additional notes

Each request receives a unique:

`PR-YYYY-XXXXXX`

Request ID.

---

### 🔎 Intelligent Blood Resource Discovery

Users can explore potential blood resources using filters such as:

- Blood group
- Blood component
- City
- District
- Resource type
- Verification status

Results clearly distinguish between:

**Potential Availability**  
and  
**Verified Availability**

PRANAV does not guarantee blood availability.

---

### 🤖 PRANAV AI Assistant

The accessible AI assistant is designed to help users with:

- Blood resource navigation
- Emergency request guidance
- Request tracking
- Blood education
- Camps
- Healthcare facility guidance
- FAQs
- Simple-language interaction

The interface is designed to support:

- English
- Hindi
- Hinglish
- Voice-friendly interaction
- Low-literacy users

PRANAV AI is not intended to diagnose medical conditions or independently prescribe medication.

## ♿ Easy Mode

- Elderly
- Low-literacy
- Unfamiliar with technology
- Under emergency-related stress

Easy Mode provides:

- Larger text

- Icon + text navigation
- Simple language
- Voice support
- Guided steps
- Visual progress
